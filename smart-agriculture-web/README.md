# 智慧农业管理系统前端（比赛版）

## 1. 项目定位

本模块是智慧农业比赛项目的前端展示层，目标是用“整齐、专业、可视化”的方式展示农业业务、环境监测、预警闭环和 AI 分析能力。

---

## 2. 当前已实现功能

### 2.1 基础能力

- Vue 3 + Vite
- Vue Router 路由管理
- Pinia 状态管理
- Axios 统一请求封装
- Element Plus 后台 UI 体系

### 2.2 页面模块

- 登录页
- 首页看板
- 农田管理
- 作物管理
- 设备管理
- 环境监测
- 预警管理（已升级为闭环中心交互）
- AI 助手（已联动预警分析）
- 个人中心

### 2.3 智能预警闭环中心前端能力

- 预警概览卡（总数、高风险、待处理、已闭环、闭环率）
- 预警列表与多条件筛选
- 右侧详情工作台
  - 基本信息
  - 环境/设备快照
  - AI 原因分析
  - AI 处置建议
  - 状态流转按钮
  - 处理时间线
- 风险等级、状态标签统一展示

### 2.4 AI 助手联动能力

新增预警联动快捷入口：

- 分析最新预警
- 解释当前高风险预警
- 生成处置建议
- 生成今日异常简报

并支持结构化结果展示，避免纯文本大段输出。
