## 二、天气快照数据说明

### 1. 用途
初始化脚本中的环境监测数据，优先使用 2026-04-01 的公开天气快照作为“温度参考值”。

### 2. 温度快照
- 寿光：8℃ / 12℃
- 东港：9℃ / 15℃
- 武清：9℃ / 18℃
- 昆山：13℃ / 20℃
- 昌宁：12℃ / 24℃
- 武汉：14℃ / 25℃
- 东台：12℃ / 18℃

说明：
- 这里采用的是公开天气快照，作为比赛演示环境数据的现实参考基础。
- 为了满足系统上午、下午两个时段的曲线展示，脚本中使用了同日两个时间点的数据组织方式。

## 三、哪些字段属于“真实公开数据”

以下字段尽量直接来源于公开可核验资料：
- 农田名称
- 所在地区
- 园区或基地面积
- 主要作物类型
- 部分设备名称与装备形态
- 温度参考值

## 四、哪些字段属于“业务化推导数据”

由于公开网络通常不会直接提供某个具体温室在某一时刻的完整原始传感器日志，因此以下字段为基于真实场景做的系统化推导：
- 湿度
- 土壤湿度
- 光照强度
- PH 值
- 设备在线状态
- 设备运行状态
- 预警记录
- AI 对话记录

## 五、为什么这样处理

比赛项目既要保证数据“有真实来源”，又要保证系统“能运行、能展示、能讲解”。  
因此采用了以下策略：

1. 先使用中国公开真实农业园区、合作社、示范项目作为农田和作物场景基础。
2. 再使用公开天气快照作为环境数据中的现实依据。
3. 对公开网络无法直接获得的内部系统字段，采用贴合农业场景的业务化推导方式补齐。
4. 在本文档中明确区分“真实公开数据”和“推导数据”，保证答辩时表述真实、边界清楚。

可以这样说明：
